# 订单修改规则

## 一、发货前修改

| 修改项 | 规则 |
|---|---|
| **改地址** | 支持改省市区/详细地址，联系客服登记，**30 分钟内**处理完毕 |
| **改尺码/颜色** | 同款同价直接改，无需退换；差价需补/退 |
| **改数量** | 支持增减（活动期间满减按修改后金额重新计算） |
| **取消订单** | 支持全额退款，退款 1-3 个工作日到账 |

## 二、发货后修改

| 时机 | 可行操作 |
|---|---|
| 已发货**未揽收** | 可尝试拦截召回，拦截成功率不保证；拦截成功则按发货前流程改 |
| **已揽收在途** | 不可改地址；可派送时联系快递员改约时间，或拒收退回后重新下单 |

## 三、换码流程（同款换尺码）

1. 已收到货想换尺码：直接申请**换货**（不选退货），寄回商品
2. 2026.11 起换码**往返运费商家承担**（旧版买家承担寄回运费）
3. 目标尺码缺货时转退款处理

## 四、预售订单

- 预售期（发货前）取消：全额退款
- 预售商品改地址/改尺码：发货前随时可改

## 五、注意事项

1. 改单高峰期（大促）处理时效可能延长至 2 小时，以客服回复为准
2. 同一订单反复修改 3 次以上建议取消重拍
3. 改地址后运费按新地址重新计算（偏远地区可能补运费）
