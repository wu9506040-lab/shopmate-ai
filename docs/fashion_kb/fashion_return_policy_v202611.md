# 退换货政策（2026-11 新政版）

> 本版自 **2026-11-01** 起执行，替代 2026.06 版退换货政策。
> 与旧版冲突时，以本版为准；旧版仅用于 11 月 1 日前签收订单的历史核对。

## 一、七天无理由退换

自签收之日起 **7 天内**可申请无理由退换货，需同时满足：

1. 商品**吊牌完整未剪**，未洗涤、未穿着（试穿不影响）
2. 无洗涤剂残留气味、无线头自行修剪痕迹
3. 赠品（袜子等）一并退回且未拆封
4. **尺码不符**属无理由范围：核对尺码表后拍下错误尺码的，正常走退换流程

**运费承担（本版核心变化）**：

| 情形 | 2026.11 新政 | 说明 |
|---|---|---|
| 非质量问题退换 | **商家承担运费**（赠送运费险自动理赔） | 旧版为买家承担 8 元/单程 |
| 已开通运费险订单 | 退货运费由运费险赔付（最高 12 元） | 下单时自动赠送，无需购买 |
| 换码（同款换尺码） | 商家承担往返运费 | 直接寄回即可 |

## 二、质量问题退换（15 天保障）

自签收之日起 **15 天内**出现下列问题，**商家全额承担往返运费**，支持退货或补发：

| 问题类型 | 认定标准 |
|---|---|
| 色差 | 与详情页展示存在明显色差（不同显示器轻微偏色不属于质量问题） |
| 起球 | 新衣 15 天内严重起球（正常摩擦起球按洗护 FAQ 指引处理） |
| 开线/脱线 | 缝合处开线、纽扣脱落 |
| 破损 | 破洞、拉链损坏、印花脱落 |
| 异味 | 明显刺激性异味（新衣轻微面料味通风即散，不属于） |

> 毛衣含羊毛成分（如针织衫含绵羊毛 2.9%）属**正常材质特性**，轻微起球不判定为质量问题。

## 三、特殊品类条款

| 品类 | 特殊条款 |
|---|---|
| **加绒类**（加绒夹克/弯刀裤） | 水洗后不支持无理由退货（绒面手感不可复原）；未水洗正常退 |
| **贴身类**（POLO 领口贴肤） | 洗涤后不支持无理由退货 |
| **预售款** | 按预售页标注发货后退换，预售期可无理由取消全额退款 |
| **打折/活动商品** | 支持七天无理由，与正价商品同标准（2026.11 起生效，旧版活动商品不退） |

## 四、退款时效

| 环节 | 时效 |
|---|---|
| 商家审核 | 签收退件后 **24 小时内**审核 |
| 退款到账 | 审核通过后 1-3 个工作日（原路返回） |
| 换货补发 | 审核通过后 48 小时内发出 |

## 五、不予退换情形

1. 超过签收 7 天（质量问题超过 15 天）
2. 已水洗、吊牌剪除、明显穿着痕迹的无理由申请
3. 附件（原装衣架/包装袋）缺失影响二次销售的
4. 个人原因反复退换同一商品 3 次以上的

## 常见问法（客服检索锚点）

- **「退货运费谁出 / 退货邮费谁承担」**：2026.11 新政起非质量问题退换由**商家承担运费**（旧版为买家承担 8 元/单程）；订单已开通运费险的，退货运费由运费险赔付，最高 12 元。见「一、七天无理由退换 · 运费承担」。
- **「换码要自己出运费吗 / 换个尺码邮费谁出」**：不用，同款换尺码的往返运费由商家承担，直接寄回即可。见「一、运费承担」表。
- **「质量问题的运费呢 / 色差起球谁承担运费」**：签收 15 天内的质量问题（色差、起球、开线脱线、破损、异味）由商家全额承担往返运费。见「二、质量问题退换」。
- **「运费险怎么赔 / 能赔多少 / 要自己买吗」**：下单时自动赠送运费险，无需购买，退货运费由运费险赔付，最高 12 元。见「一、运费承担」表。
