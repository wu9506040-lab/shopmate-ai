## 七、量体方法

- **胸围**：沿腋下最丰满处水平围量一周，软尺贴身不勒紧
- **腰围**：肚脐上方 2 指处水平围量一周（裤装选码以此为准）
- **衣长**：后领中点垂直量至下摆
- **裤长**：腰头上沿垂直量至裤脚

## 八、选码原则

1. 表值为**平铺手工测量**，1-3CM 误差属正常范围
2. 宽松版型（本店主线）按推荐表选码即可；喜欢修身效果建议小一码
3. 身高体重跨界（如 175cm/95kg）时**以体重维度优先**
4. 加绒款（加绒夹克/弯刀裤）内穿厚衣场景建议**大一码**
5. 推荐表仅供参考，不作为退换货唯一依据（详见退换货政策 2026.11 版）
